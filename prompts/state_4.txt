## State: **Reach Object**

---

## 🎯 GOAL
Move precisely toward the desired object until you are close enough to stop and describe it.

---

## 🧠 POLICY RULES

🏠 **ROOM CONSISTENCY**:
- You entered `Reach Object` because the target object was found. Try to maintain the room identification from `agent_memory` or the previous state rather than re-evaluating it.
- Visually similar features (white cabinets, counters, sinks) exist in multiple rooms. To avoid confusion, it is best to keep the `room` value consistent with your memory.

🎯 **APPROACH & ALIGNMENT**:
- Advance gradually toward the object using small forward steps (`A1`) and evaluating the situation.
- If the object is not centered, use small rotational adjustments (`B1`, `C1`) to align it in the center of the frame.
- Use lateral movements (`D1` or `D2`) when the object is close but slightly off-center. 
- Try to show the object aligned and centered, use the most suitable move to approach.

🛑 **STOPPING CRITERIA**:
- Consider the object “close enough” if:
  - It fills at least 40% of the image width **or** its top and bottom edges are cropped in the view,
  - And it appears roughly centered (within ±20% from the horizontal center).
- If the object is very tall or vertical (like a mirror) with top/bottom cropped, you can just move forward or back (taking care of crashing) until close without over-adjusting the alignment.
- If these conditions are not met, continue approaching or adjusting alignment.

⚠️ **LOST TRACKING**:
- If the object disappears from view for 2 or more consecutive steps, you should transition to `Search Object` and return movement = `E` to re-evaluate your surroundings.
- Avoid continuing forward if only a flat wall or undistinguished surface is visible.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command from the list below:

### A. Forward movement:
- `A1`: move forward 10 cm

### B. Left rotation:
- `B1`: rotate 15°

### C. Right rotation:
- `C1`: rotate 15°

### D. Lateral movement:
- `D1`: move 10 cm left
- `D2`: move 10 cm right

### E. Transition:
- `E`: issue when transitioning to `Search Object` after the object is missing for a few steps, or when transitioning to `Describe Object`.

---

## 🔄 OUTPUT STATE RULES

Choose the next FSM state:

- `Reach Object`: if the object is still visible but not yet reached or aligned.
- `Describe Object`: if the object is approximately centered, large, and visually close based on the conditions above.
- `Search Object`: if the object has disappeared from view for multiple consecutive steps, no recognizable object is in frame, or visual tracking is lost.

---

## 📝 NOTES

- Try to avoid overshooting: stop once the object appears large and approximately centered.
- Rotations are usually unnecessary if the object is already aligned.
- If the output state is `Describe Object`, move with `E`.
