## State: **Search open Door**

---

## 🎯 GOAL  
Systematically sweep the environment to detect an open door. Follow a structured **rotate → advance → rotate** cycle. Never spin in place indefinitely.

---

## 🕹️ MOVEMENT COMMANDS
Only return ONE command:
- `A1`: move forward 10 cm (Use to explore and change location)
- `A2`: move forward 30 cm (use when the path ahead is clearly open)
- `B2`/`B3`: rotate left
- `C2`/`C3`: rotate right
- `E`: transition command — to `Oriented Towards Door` (open door found) OR to `Search Object` (already in target room)

---

## 🧠 POLICY RULES (Priority Ordered)

✅ **PRIORITY 0: ALREADY IN TARGET ROOM (CHECK FIRST)**:
- Before anything else, compare the room you are currently in against the room mentioned in the user query (e.g., "find the sink in the bathroom" → target room is "bathroom").
- If the visual cues (floor pattern, objects, room features) confirm you are **already inside the correct target room**, do **NOT** search for a door.
- **Immediately transition to `Search Object`** with movement `E`.
- This overrides all navigation rules below. You are where you need to be — start looking for the object.

🚨 **PRIORITY 1: ABSOLUTE SAFETY — CABINETS / WALLS / CORNERS**:
- If the object directly in front is a CLOSED DOOR, CABINET, CLOSET, or WALL, you are FORBIDDEN from using `A1`.
- CRITICAL: Always rotate in the SAME direction as your `previous_movement` (e.g., if previous was C, use C; if B, use B) to avoid infinite oscillation loops. NEVER reverse your rotation immediately.

⚠️ **WRONG ROOM ESCAPE**: If you just realized you are in the wrong room, your immediate priority is to find the door you just came through. Execute a large rotation (B3 or C3, 90 degrees) to quickly turn around and locate the exit. Do not waste time with small 15-degree rotations.

🔁 **PRIORITY 2: ANTI-ROTATION-LOOP**:
- Count consecutive rotations in `mov_history` (any sequence of B or C commands with no A in between).
- If there are **3 or more consecutive rotations** and no door is visible, you are spinning in place. **STOP rotating. Return `A1` to move forward** and get a new vantage point, even if the path looks tight.
- Only resume rotating after you have moved forward at least once.


3️⃣ **PRIORITY 3 (OPEN DOOR DETECTED)**:
- If you see an open door or open void leading to another room, transition to `Oriented Towards Door` (`E`) **ONLY IF IT COULD PLAUSIBLY LEAD TO THE OBJECTIVE**.
- **Do NOT approach it diagonally with `A1`**. Let the Oriented state handle the approach.

4️⃣ **PRIORITY 4 — STRUCTURED SWEEP (ROTATE → ADVANCE → ROTATE)**:
- After each rotation step (B or C), if the path ahead is OPEN and CLEAR and no door was found: return `A1` to move to a new vantage point before rotating again.
- After each forward step (A): if no door is visible, resume rotating in the same direction as before.
- This creates a deliberate sweep pattern that covers new ground rather than spinning from the same spot.
- If the path is NOT clear after rotating: continue rotating (same direction). Do NOT force `A1` into a wall.

5️⃣ **PRIORITY 5 (CLEAR OPEN SPACE)**:
- If the path ahead is a large open space with no obstacles, use `A2` (30 cm) to move efficiently toward the center of the room.
- Only rotate once you reach a wall, corner, or obstacle.
---

## 🔄 OUTPUT STATE RULES
- `Search Object`: You have confirmed you are **already in the correct target room** — stop navigating, start searching for the object.
- `Oriented Towards Door`: An open door is detected and selected as a candidate.
- `Search open Door`: Still looking, moving, or dodging a closed door/cabinet.
