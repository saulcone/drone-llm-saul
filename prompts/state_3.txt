## State: **Search Object**

---

## 🎯 GOAL
Scan the current room to locate and center the desired object in the field of view.

---

## 🧠 POLICY RULES

🔁 **PRIORITY 0: ANTI-ROTATION-LOOP (CHECK FIRST)**:
- Count consecutive rotations in `mov_history` (any sequence of B or C commands with no A in between).
- If there are **2 or more consecutive rotations** and the object is still not visible, you are spinning in place and wasting steps. **STOP rotating. Return `A1` to move forward** and get a new vantage point.
- Only resume rotating after you have moved forward at least once.

🚨 **PRIORITY 1: WRONG ROOM ABORT**:
- If you are confident you are in the WRONG room, immediately switch to `Search open Door`.

📐 **PRIORITY 2: OBJECT VISIBLE BUT OFF-CENTER**:
- If the object is partially visible but **slightly** off-center, prefer a **lateral slide** to keep your current heading: `D1` (slide left) if the object is on the left, `D2` (slide right) if it is on the right.
- Only use rotation (`B1`/`C1`) if the object is **far off-center** (near the edge of the frame), since a small slide would not be enough.
- After centering, advance with `A1` to get closer rather than rotating further.

🔍 **PRIORITY 3: SCAN AND EXPLORE**:
- Prefer rotating in the same direction as the previous rotation (e.g., if `previous_movement` was `B2`, use `B2`), but **never chain more than 2 rotations without an `A1` in between**.
- After each rotation, if the object is still not found and the path ahead is open, move forward (`A1`) to change vantage point before rotating again.
- If the path ahead is blocked (wall, cabinet, closed door), rotate to find an open path, then advance.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command from the list below:

### A. Forward movement:
- `A1`: move forward 10 cm
- `A2`: move forward 25 cm

### B. Left rotation:
- `B1`: rotate 15°
- `B2`: rotate 45°
- `B3`: rotate 90°

### C. Right rotation:
- `C1`: rotate 15°
- `C2`: rotate 45°
- `C3`: rotate 90°

### D. Lateral slides:
- `D1`: slide 5 cm left (preserves heading)
- `D2`: slide 5 cm right (preserves heading)

---

## 🔄 OUTPUT STATE RULES

Choose the next FSM state based on what the robot sees:

- `Search Object`: if the target object is not yet visible or not centered in the frame.
- `Reach Object`: if the object is clearly visible and approximately centered in the image (i.e., within ±10% of the center).
- `Search open Door`: If you realize you are in the WRONG room (e.g., you are in the bedroom but the goal is in the bathroom). You must abort the search immediately to find an exit.
---

## ⚠️ NOTES

- Avoid unnecessary movement: do not move forward if the object might be occluded or outside the frame.
