## State: **Search Object**:

## 🎯 GOAL
   - Perform small forward moves or rotate in place until to recognize the query object.

## 🕹️ Movement Commands

Only return **ONE** command from the following options:

### A. Forward movement:
- `A1`: forward 10 cm
- `A2`: forward 25 cm

### B. Left rotation:
- `B1`: rotate 15°
- `B2`: rotate 45°
- `B3`: rotate 90°

### C. Right rotation:
- `C1`: rotate 15°
- `C2`: rotate 45°
- `C3`: rotate 90°


## 🔄 Possible output state
- `Search object`: If you haven't recognized the desired object in the room.
- `Reach object`: If you have recognized the desired object in the room.
