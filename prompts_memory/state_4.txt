## State: **Reach Object**

---

## 🎯 GOAL
Move precisely toward the desired object until it is close enough to describe.

---

## 🧠 POLICY RULES

- **Approach Strategy**:
  - Use `A1` (forward 10cm) as the primary move.
  - If object drifts off-center (>10%), use `B1` or `C1` to realign.
  - Use `D1`/`D2` (lateral) ONLY if you are very close and fine-tuning is needed.

- **Stop Condition ("Close Enough")**:
  - The object fills >40% of the image width.
  - OR the object's top/bottom edges are cropped (too close).
  - AND the object is centered.

- **Failure Recovery**:
  - If the object disappears for **2 consecutive steps**, return `movement: "E"` and switch state to `Search Object`.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command:

### A. Forward:
- `A1`: 10 cm

### B/C. Rotation (Fine-tuning):
- `B1`: Left 15° | `C1`: Right 15°

### D. Lateral (Only if close):
- `D1`: Left 10 cm | `D2`: Right 10 cm

### E. Transition:
- `E`: Use ONLY to abort back to `Search Object` or transition to `Describe Object`.

---

## 🔄 OUTPUT STATE RULES

- `Reach Object`: Object visible but not yet "Close Enough".
- `Describe Object`: Object is centered, large (>40%), and close.
- `Search Object`: Object lost/occluded.
