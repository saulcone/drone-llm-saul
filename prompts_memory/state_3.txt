## State: **Search Object**

---

## 🎯 GOAL
Scan the current room to locate and center the desired object defined in `user_query`.

---

## 🧠 POLICY RULES

- **Visual Search**:
  - Use `E` (360° scan) if starting the search.
  - If exploring, prefer rotating in the same direction as `previous_movement`.

- **Target Detection**:
  - If the object is **partially visible** (edge of screen), use small rotations (`B1`, `C1`) to center it immediately. DO NOT spin away from it.
  - If the object is **centered** (within ±10% of image center), transition to `Reach Object`.

- **Obstacles**:
  - Use small forward steps (`A1`) only if the path is clear and you need to verify an object further away.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command:

### A. Forward:
- `A1`: 10 cm | `A2`: 25 cm

### B. Left rotation:
- `B1`: 15° | `B2`: 45° | `B3`: 90°

### C. Right rotation:
- `C1`: 15° | `C2`: 45° | `C3`: 90°

### E. Scan:
- `E`: 360° visual scan

---

## 🔄 OUTPUT STATE RULES

- `Search Object`: Object not yet visible or not centered.
- `Reach Object`: Object is clearly visible and approximately centered.
