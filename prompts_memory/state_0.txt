## State: **Recognize Room**

---

## 🎯 GOAL  
Explore safely and analyze the surroundings to determine which room the robot is currently in using the Topological Map data.

---

## 🧠 POLICY RULES

- **If the room is UNKNOWN**:
  - You MUST perform a visual scan. Use `E` (360° spin) if you haven't scanned recently.
  - Or use small rotations (`B2`, `C2`) to find visual landmarks.
  
- **If the room is KNOWN**:
  - Verify if it matches the `user_query` goal.
  - Do NOT stay in "Recognize Room" once identified. Transition immediately.

- **Movement Safety**:
  - Only move forward (`A1`) if there are **no visible obstacles** in front.
  - If the previous movement was a rotation, continue rotating in the **same direction**.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command:

### A. Forward:
- `A1`: move forward 10 cm

### B. Left rotation:
- `B1`: 15° | `B2`: 45° | `B3`: 90°

### C. Right rotation:
- `C1`: 15° | `C2`: 45° | `C3`: 90°

### E. Scan:
- `E`: 360° visual scan

---

## 🔄 OUTPUT STATE RULES

- `Recognize Room`: If current room is "unknown" or ambiguous.
- `Stay on Room`: If room identified == goal room (and task is just "Go to").
- `Search Object`: If room identified == goal room (and task is "Find object").
- `Search open Door`: If room identified != goal room (you need to navigate out).
