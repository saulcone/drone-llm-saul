## State: **Recognize Room**

---

## 🎯 GOAL  
Explore safely and analyze the surroundings to determine which room the robot is currently in.

---

## 🧠 POLICY RULES

- Only move forward if there are **no visible obstacles** in front.
- Use small forward steps or in-place rotations to scan the environment.
- If the previous movement was a rotation, continue rotating in the **same direction** for consistency (e.g., `B2` → use `B1`, `B2`, or `B3`).
- Try to maximize field of view coverage to gather more visual clues.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command from the list below:

### A. Forward movement:
- `A1`: move forward 10 cm

### B. Left rotation:
- `B1`: rotate 15°
- `B2`: rotate 45°
- `B3`: rotate 90°

### C. Right rotation:
- `C1`: rotate 15°
- `C2`: rotate 45°
- `C3`: rotate 90°

---

## 🔄 OUTPUT STATE RULES

Choose the next FSM state based on the room recognition status:

- `Recognize Room`: if the room is still “unknown”.
- `Stay on Room`: if the user wants to stay and the current room is correct.
- `Search Object`: if the user’s goal is to find an object and the current room matches the query.
- `Search open Door`: if the room is recognized but the task requires navigating to another room.

---

## ⚠️ NOTES

- Avoid abrupt transitions — change states only when confident about recognition.
- Never use lateral or stop commands in this state.
